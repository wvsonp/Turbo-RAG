# 4.3 Prometheus metrics on all services

## Goal

Every service exposes `GET /metrics` in Prometheus exposition format; replace Phase 1 stubs with real counters/histograms.

## Scope

- Request latency, error rate, ingestion throughput, embedding batch size
- Annotate Services for scraping

## Prerequisites

- [4.2](4.2-prometheus-grafana.md)
- Phase 1.7 skeleton `/metrics` optional starting point

## Acceptance criteria

- [ ] `curl /metrics` on each service returns valid Prometheus text.
- [ ] Grafana can query `http_requests_total` (or equivalent) per service.
- [ ] No high-cardinality labels (avoid raw `user_id` on every metric).

## Dependencies

- [4.2](4.2-prometheus-grafana.md)
