# 1.4 Artifact Registry

## Goal

Docker repository for all service images with a consistent tagging scheme (`{git-sha}`).

## Scope

- `infra/modules/artifact_registry/`
- Wire module in root `infra/main.tf`
- Local `docker push` auth configured

## Prerequisites

- [1.1](1.1-gcp-bootstrap.md), [1.2](1.2-terraform-layout.md)
- API `artifactregistry.googleapis.com`

## Implementation notes

```hcl
resource "google_artifact_registry_repository" "docker" {
  location      = var.region
  repository_id = "rag-platform"
  format        = "DOCKER"
}
```

Image naming:

`{REGION}-docker.pkg.dev/{PROJECT_ID}/rag-platform/{service}:{git-sha}`

```bash
gcloud auth configure-docker us-central1-docker.pkg.dev
```

## Acceptance criteria

- [ ] Repository exists in Terraform; `terraform apply` creates it in dev.
- [ ] `gcloud artifacts repositories list` shows `rag-platform`.
- [ ] Test push of a tiny image (e.g. `hello-world` retagged) succeeds.
- [ ] Module outputs repository URL for Helm/CI consumption.

## Validation commands

```bash
cd infra && terraform apply -var-file=environments/dev.tfvars -target=module.artifact_registry
gcloud artifacts repositories describe rag-platform --location=us-central1
```

## Rollback / cleanup

- Delete images via Console or `gcloud artifacts docker images delete` before destroying repo if needed.

## Production notes

- Enable cleanup policies (keep last N tags per service).
- CI uses WIF + `roles/artifactregistry.writer` (Phase 5)—not user credentials.
