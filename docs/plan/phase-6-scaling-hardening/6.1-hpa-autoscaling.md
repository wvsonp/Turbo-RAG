# 6.1 HPA + node autoscaling

## Goal

Query service scales on CPU and custom metric `active_queries`; worker pool uses Spot with cluster autoscaler.

## Scope

- HPA manifest in `helm/query/`
- Custom metrics adapter or Prometheus adapter
- GKE cluster autoscaler / node auto-provisioning documented

## Prerequisites

- Phase 3 query deployed, Phase 4 metrics

## Acceptance criteria

- [ ] Under load test, replica count increases above `minReplicas`.
- [ ] Scales down after load stops (within stabilization window).
- [ ] Spot worker pool scales 0→N for Prefect jobs.

## Dependencies

- Phase 3, [4.3](../phase-4-observability/4.3-metrics-endpoints.md)
