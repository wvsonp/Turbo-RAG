# 4.2 Prometheus + Grafana

## Goal

Cluster and app metrics collection with `kube-prometheus-stack` (or equivalent).

## Scope

- Helm install in monitoring namespace
- ServiceMonitor / PodMonitor for app namespaces

## Prerequisites

- Phase 1 GKE

## Acceptance criteria

- [ ] Prometheus targets show UP for platform services.
- [ ] Grafana admin access configured; datasource points to Prometheus.
- [ ] Default Kubernetes dashboards available.

## Dependencies

- [1.3 GKE](../phase-1-foundation/1.3-gke-cluster.md)
