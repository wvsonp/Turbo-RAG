# 6.4 Architecture Decision Records

## Goal

Documented trade-offs for handoff and interviews.

## Scope

- `docs/adr/` with numbered ADRs:
  - Qdrant vs Pinecone
  - Prefect vs Airflow
  - Langfuse vs LangSmith
  - Workload Identity vs SA JSON keys
  - Pub/Sub vs Kafka
  - Vertex embeddings vs OpenAI

## Prerequisites

- Decisions made across Phases 1–5

## Acceptance criteria

- [ ] At least six ADRs in MADR or similar format (context, decision, consequences).
- [ ] Each ADR linked from README or project roadmap.
- [ ] Status field: Accepted (not Proposed only).

## Dependencies

- Prior phases (content), no infra blocker
