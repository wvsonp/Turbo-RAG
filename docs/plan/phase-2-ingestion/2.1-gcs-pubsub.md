# 2.1 GCS bucket + Pub/Sub notifications

## Goal

Object uploads to GCS trigger Pub/Sub messages that start ingestion.

## Scope

- `infra/modules/pubsub/` wired in root
- GCS bucket + notification config (Terraform)
- Topic + subscription for ingestion workers

## Prerequisites

- Phase 1 complete ([1.10 Workload Identity](../phase-1-foundation/1.10-workload-identity.md))

## Acceptance criteria

- [ ] Uploading a test file to the bucket publishes a message to the topic.
- [ ] Subscription deliverable by test subscriber (`gcloud pubsub subscriptions pull`).
- [ ] IAM: ingestion SA can consume; bucket SA notifications configured.
- [ ] Resources defined in Terraform only.

## Validation commands

```bash
echo test > /tmp/sample.txt
gcloud storage cp /tmp/sample.txt gs://<ingestion-bucket>/incoming/sample.txt
gcloud pubsub subscriptions pull <subscription> --auto-ack --limit=1
```
