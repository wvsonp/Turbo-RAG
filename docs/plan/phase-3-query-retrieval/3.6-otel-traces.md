# 3.6 OpenTelemetry traces (query path)

## Goal

One trace per request with spans for retrieve, rerank, and generate—exported to collector (full collector in Phase 4.5).

## Scope

- OTel SDK in query service
- Trace context propagation headers

## Prerequisites

- [3.2](3.2-hybrid-search-rrf.md) minimum; [4.5](../phase-4-observability/4.5-otel-collector.md) for full pipeline

## Acceptance criteria

- [ ] Trace visible in backend (Jaeger/Cloud Trace/collector UI) for sample request.
- [ ] Span attributes include `document_ids`, latency ms per stage.

## Dependencies

- [3.2+](3.2-hybrid-search-rrf.md); pairs with [4.5](../phase-4-observability/4.5-otel-collector.md)
