# 3.2 Hybrid search + RRF

## Goal

Combine dense (Qdrant ANN) and sparse (BM25) retrieval with Reciprocal Rank Fusion.

## Scope

- Qdrant dense search + BM25 index (in Qdrant sparse or sidecar—document choice)
- RRF merge → candidate list (e.g. top 50)

## Prerequisites

- [3.1](3.1-query-api-skeleton.md), Phase 2 data in Qdrant

## Acceptance criteria

- [ ] Query returns fused ranked candidates for known test questions.
- [ ] Unit tests cover RRF with fixed candidate lists.
- [ ] Latency logged per step (prep for OTel).

## Dependencies

- [3.1](3.1-query-api-skeleton.md), Phase 2
