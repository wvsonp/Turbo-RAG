# 3.3 Cross-encoder reranker

## Goal

Rerank top-50 fused candidates to top-5 using `ms-marco-MiniLM-L-6-v2`.

## Scope

- Model load strategy (memory, warm-up)
- Rerank step in query pipeline

## Prerequisites

- [3.2](3.2-hybrid-search-rrf.md)

## Acceptance criteria

- [ ] Response includes final top-5 chunks with scores.
- [ ] Rerank step bounded by timeout; degrades gracefully if model slow.
- [ ] Integration test with golden query returns expected doc in top-5.

## Dependencies

- [3.2](3.2-hybrid-search-rrf.md)
