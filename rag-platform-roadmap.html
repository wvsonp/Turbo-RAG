02
Recommended Tech Stack
Why each tool — justified for MLOps/ML Engineering conversations
Orchestration

Prefect 2.x

Orchestrates chunking, embedding, and eval pipelines as typed flows with retries, caching, and artifact tracking.

→ Better DX than Airflow for ML; native Python; deployable on GKE
Vector DB

Qdrant

Self-hosted on GKE. Supports dense + sparse vectors (hybrid search), filtering by payload, and named collections.

→ More MLOps-impressive than Pinecone; you own the infra
LLM Tracing

Langfuse

Traces every LLM call, token usage, latency, and RAG span. Self-hosted on Cloud Run. Supports evals and scoring.

→ Open-source alternative to LangSmith; shows you understand LLM observability
Metrics

Prometheus + Grafana

Prometheus scrapes service metrics (latency, error rate, embedding throughput). Grafana dashboards per service layer.

→ Industry standard; shows you know the difference between tracing vs metrics
Distributed Tracing

OpenTelemetry

Instruments all services with traces and spans. Exports to Langfuse (LLM) and Prometheus (infra). Single SDK.

→ Shows you know the three pillars: logs, metrics, traces
RAG Evaluation

RAGAS

Measures faithfulness, answer relevancy, context precision. Runs as an async Prefect worker after each retrieval batch.

→ Shows you measure quality, not just ship the system
Infrastructure

Terraform + GKE

All GCP resources defined as code: GKE cluster, CloudSQL, Pub/Sub topics, IAM, Artifact Registry, Workload Identity.

→ IaC is non-negotiable for senior MLOps roles
CI/CD

GitHub Actions + Helm

Build → test → push to Artifact Registry → helm upgrade on GKE. Separate pipelines per service.

→ Shows deployment lifecycle understanding; Helm = Kubernetes packaging
Model Registry

MLflow

Track embedding model experiments, register chunking configurations as "models", log RAGAS scores per run.

→ Connects ML lifecycle to the platform; key MLOps interview topic
Messaging

GCP Pub/Sub

Decouples ingestion triggers from workers. Upload to GCS → Pub/Sub event → Prefect flow triggered → workers process.

→ Event-driven architecture is core to scalable ML pipelines
Embeddings

Vertex AI Embeddings

Use text-embedding-004 from Google. Fall back to HuggingFace sentence-transformers for local testing.

→ Shows you know managed vs self-hosted tradeoffs
Chunking

Unstructured.io + LangChain Splitters

Unstructured handles PDFs/HTML/DOCX parsing. LangChain RecursiveCharacterTextSplitter with configurable chunk_size + overlap.

→ Multiple strategies = rich discussion in interviews

🎓 You'll be able to talk about:
  • Why a separate 1.2b Network step (VPC + PSA + Cloud NAT) is what unlocks private GKE nodes and private-IP Cloud SQL
  • Workload Identity (KSA → GSA) vs service-account JSON keys — least privilege + no key rotation
  • Terraform layout: remote state on GCS, modules per resource group, dev.tfvars/prod.tfvars for parity
  • StatefulSet vs Deployment for Qdrant — stable network identity + PVC per replica
  • Secret Manager + CSI driver vs K8s Secret objects (etcd) for third-party API keys
  • Multi-stage Docker builds + {git-sha} tagging for reproducible deploys
