# 3.5 SSE streaming responses

## Goal

Stream LLM tokens to clients via Server-Sent Events after retrieval context is assembled.

## Scope

- `POST /query/stream` or stream flag on existing endpoint
- Vertex or configured LLM provider

## Prerequisites

- [3.3](3.3-reranker.md), Secret Manager for any non-WI API keys

## Acceptance criteria

- [ ] Client receives incremental SSE events until `[DONE]`.
- [ ] Connection drop cancels upstream generation where supported.
- [ ] Langfuse trace linked (Phase 4) optional stub OK initially.

## Dependencies

- [3.3](3.3-reranker.md)
