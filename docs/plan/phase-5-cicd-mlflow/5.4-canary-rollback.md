# 5.4 Canary deployment + automated rollback

## Goal

Route fraction of traffic to new embedding model; compare RAGAS scores; rollback if `faithfulness` drops below threshold.

## Scope

- Traffic split (Helm weights or feature flag)
- RAGAS evaluation job in CI or scheduled workflow
- Rollback via Helm revert + registry stage change

## Prerequisites

- [5.3](5.3-model-registry.md), Phase 3 query path, observability metrics

## Acceptance criteria

- [ ] 10% canary configurable in values.
- [ ] Simulated regression triggers rollback in dev drill.
- [ ] Post-rollback RAGAS returns to baseline in test harness.

## Dependencies

- [5.3](5.3-model-registry.md), Phase 3–4
