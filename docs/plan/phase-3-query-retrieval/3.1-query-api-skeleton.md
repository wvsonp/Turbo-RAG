# 3.1 Query API skeleton

## Goal

FastAPI query service with validated request/response models and async handlers—deployed via Helm.

## Scope

- `services/query/` — `POST /query` stub returning mock or empty result
- Pydantic models for query request/response

## Prerequisites

- Phase 1 Helm + skeleton patterns

## Acceptance criteria

- [x] `POST /query` returns 200 with schema-valid JSON.
- [x] OpenAPI docs available at `/docs`.
- [x] Deployed on app node pool; probes pass.
