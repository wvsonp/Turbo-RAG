# 1.3 GKE cluster

## Goal

Standard GKE cluster with three node pools and **Workload Identity** enabled at cluster level.

## Scope

- `infra/modules/gke/`
- System, application, and Spot/preemptible worker pools
- Workload Identity pool configured

## Prerequisites

- [1.2 Terraform layout](1.2-terraform-layout.md)
- [1.2b Network](1.2b-network-foundation.md) recommended before private cluster / Cloud SQL integration

## Implementation notes

**Cluster:** Standard (not Autopilot) for explicit node-pool control.

| Pool | Machine | Scaling | Purpose |
| ---- | ------- | ------- | ------- |
| system | e2-standard-2 | fixed 2 | system / infra addons |
| app | e2-standard-4 | 1–5 | platform services |
| worker | e2-standard-2 Spot | 0–3 | Prefect workers |

```hcl
workload_identity_config {
  workload_pool = "${var.project_id}.svc.id.goog"
}
```

**Quota:** Regional SSD/disk quotas caused apply failures—see `docs/history/gke.md`. Set explicit disk size/type in node pool config.

**Minimal observability (do now):** Enable logging and monitoring components; confirm `kubectl get nodes` after apply.

## Acceptance criteria

- [ ] `terraform apply -var-file=environments/dev.tfvars` creates cluster and pools in dev.
- [ ] `gcloud container clusters get-credentials` works; `kubectl get nodes` shows Ready nodes.
- [ ] Workload Identity pool matches `{project_id}.svc.id.goog`.
- [ ] All three node pools present with expected autoscaling bounds.
- [ ] Cluster and pool settings captured in Terraform (no console-only drift).

## Validation commands

```bash
cd infra
terraform plan -var-file=environments/dev.tfvars
terraform apply -var-file=environments/dev.tfvars
gcloud container clusters get-credentials rag-platform --region=us-central1 --project=turbo-rag
kubectl get nodes -o wide
```

## Rollback / cleanup

```bash
terraform destroy -target=module.gke -var-file=environments/dev.tfvars
```

## Production notes

- Enable release channel / maintenance window for prod.
- Separate cluster per environment or separate project—do not share dev cluster for prod traffic.
