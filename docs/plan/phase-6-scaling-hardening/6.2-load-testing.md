# 6.2 Load testing (Locust)

## Goal

Demonstrate SLO under 100 concurrent users: P99 latency within target (e.g. &lt; 3s for query path).

## Scope

- Locust scenarios in repo
- Run against dev/staging endpoint
- Results captured in `docs/history/` or CI artifact

## Prerequisites

- [6.1](6.1-hpa-autoscaling.md), full query + observability stack

## Acceptance criteria

- [ ] Locust report generated for 100 VUs, documented duration.
- [ ] P99 and error rate recorded; compared to SLO.
- [ ] Bottleneck noted (if any) with follow-up item.

## Dependencies

- [6.1](6.1-hpa-autoscaling.md)
