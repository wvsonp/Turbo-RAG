# 4.5 OpenTelemetry Collector (DaemonSet)

## Goal

Single export path for traces from all services; completes [3.6](../phase-3-query-retrieval/3.6-otel-traces.md) wiring.

## Scope

- OTel Collector DaemonSet
- Exporters: Cloud Trace and/or Tempo/Jaeger for dev

## Prerequisites

- [3.6](../phase-3-query-retrieval/3.6-otel-traces.md)

## Acceptance criteria

- [ ] Collector pods Running on each node.
- [ ] Query request trace end-to-end in chosen backend.
- [ ] Collector config in Helm/Git—not hand-edited in cluster only.

## Dependencies

- [3.6](../phase-3-query-retrieval/3.6-otel-traces.md)
