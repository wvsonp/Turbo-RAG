# 3.4 JWT auth + RBAC

## Goal

Authenticate callers via JWT; authorize `admin`, `user`, `readonly` roles on routes.

## Scope

- Middleware on query (and optionally api gateway)
- Role matrix documented

## Prerequisites

- [3.1](3.1-query-api-skeleton.md)

## Acceptance criteria

- [ ] Unauthenticated requests to protected routes return 401.
- [ ] `readonly` cannot call admin-only routes.
- [ ] Valid token allows `/query`; tests cover role matrix.

## Production notes

- Prefer external IdP or IAP at ingress for prod; JWT acceptable for portfolio dev.

## Dependencies

- [3.1](3.1-query-api-skeleton.md)
