# 2.3 Ingestion flow (parse → chunk → embed → upsert)

## Goal

End-to-end Prefect flow: read object → parse → chunk → embed (Vertex `text-embedding-004`) → Qdrant upsert → PostgreSQL metadata.

## Scope

- `services/workers/` flows
- Batched embedding calls
- Collection/schema conventions documented

## Prerequisites

- [2.2](2.2-prefect-on-gke.md), Qdrant [1.9](../phase-1-foundation/1.9-qdrant.md), Cloud SQL [1.5](../phase-1-foundation/1.5-cloudsql.md)

## Acceptance criteria

- [ ] Single PDF/text upload results in searchable vectors in Qdrant.
- [ ] Metadata row exists in `rag_metadata` for the document.
- [ ] Flow retries transient Vertex/Qdrant errors with backoff.
- [ ] End-to-end run completes in dev under documented size limit (e.g. 10-page PDF).

## Validation commands

```bash
# after upload trigger
curl -X POST http://qdrant:6333/collections/<name>/points/count
psql -c "SELECT id, source_uri FROM documents LIMIT 5;"
```
