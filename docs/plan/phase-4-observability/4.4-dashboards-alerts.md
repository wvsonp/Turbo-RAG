# 4.4 Dashboards + alerting

## Goal

Operational dashboards and Alertmanager rules for SLO-style signals.

## Scope

- Dashboards: ingestion throughput, query P50/P95/P99, token usage, RAGAS scores (when available)
- Alerts: `error_rate > 1%`, `p99_latency > 3s`, `qdrant_disk_usage > 80%`

## Prerequisites

- [4.2](4.2-prometheus-grafana.md), [4.3](4.3-metrics-endpoints.md), Phase 3 traffic

## Acceptance criteria

- [ ] Dashboard JSON exported to `docs/` or `helm/monitoring/`.
- [ ] Test alert fires in dev when threshold artificially lowered.
- [ ] Runbook link in alert annotation (can be README section).

## Dependencies

- [4.2](4.2-prometheus-grafana.md), [4.3](4.3-metrics-endpoints.md)
