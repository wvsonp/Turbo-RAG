# 5.2 MLflow tracking server

## Goal

Central experiment tracking with GCS artifact store and Cloud SQL backend (`mlflow` database).

## Scope

- MLflow server deployment (GKE or Cloud Run)
- Artifact bucket IAM via Workload Identity

## Prerequisites

- [1.5 Cloud SQL](../phase-1-foundation/1.5-cloudsql.md), GCS bucket for artifacts

## Acceptance criteria

- [ ] `mlflow.set_tracking_uri` from worker pod logs experiment successfully.
- [ ] Artifacts stored in GCS; metadata in Cloud SQL.
- [ ] Server not publicly open without auth.

## Dependencies

- Phase 1 data plane; unblocks [2.4](../phase-2-ingestion/2.4-chunking-mlflow.md) fully
