# 2.2 Prefect on GKE

## Goal

Prefect server/agent or workers run on the **worker** node pool (Spot) and can execute flows triggered by Pub/Sub.

## Scope

- Helm or manifests for Prefect 2.x
- Work pool / work queue aligned with K8s jobs
- WI for GCS, Vertex, Qdrant access

## Prerequisites

- [2.1](2.1-gcs-pubsub.md), Phase 1 GKE worker pool

## Acceptance criteria

- [ ] Prefect UI or API reachable inside cluster (ingress optional).
- [ ] Sample flow runs successfully as K8s job on worker pool.
- [ ] Flow run logs visible in Prefect UI.

## Validation commands

```bash
kubectl get pods -n prefect
prefect deployment run hello-flow  # or equivalent CLI
```

## Dependencies

- [2.1](2.1-gcs-pubsub.md)
