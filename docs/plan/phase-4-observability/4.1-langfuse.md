# 4.1 Langfuse (self-hosted)

## Goal

LLM tracing UI with traces for ingestion and query paths; backed by Cloud SQL `langfuse` database.

## Scope

- Deploy Langfuse (Cloud Run or GKE—document choice)
- SDK instrumentation hooks in query + workers

## Prerequisites

- [1.5 Cloud SQL](../phase-1-foundation/1.5-cloudsql.md)

## Acceptance criteria

- [ ] Langfuse UI reachable (auth protected).
- [ ] Sample query produces trace → span → generation with token counts.
- [ ] No LLM payloads stored outside GCP if that is a project requirement.

## Dependencies

- Phase 1 data plane
