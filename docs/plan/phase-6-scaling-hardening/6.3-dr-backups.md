# 6.3 DR: backups + Qdrant snapshots

## Goal

Recoverable data plane: Cloud SQL backups/PITR verified; Qdrant collections snapshotted to GCS daily.

## Scope

- Cloud SQL: backup + PITR (prod); restore drill documented
- Prefect cron flow: Qdrant snapshot → GCS
- **Not** deferred entirely to Phase 6 for SQL—enable backups at [1.5](../phase-1-foundation/1.5-cloudsql.md); this step validates restore

## Prerequisites

- [1.5](../phase-1-foundation/1.5-cloudsql.md), [1.9](../phase-1-foundation/1.9-qdrant.md), Phase 2 workers

## Acceptance criteria

- [ ] Cloud SQL point-in-time recovery tested on dev clone or documented prod drill.
- [ ] GCS bucket contains dated Qdrant snapshots.
- [ ] Restore procedure documented in `docs/history/` (&lt; 1 page).
