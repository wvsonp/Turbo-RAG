# 5.3 MLflow Model Registry

## Goal

Register chunking configs and embedding model versions; promote stages `Staging` → `Production`.

## Scope

- Registry entries for chunking presets and embedding model IDs
- Helm values read active production version

## Prerequisites

- [5.2](5.2-mlflow-server.md), Phase 2 chunking experiments

## Acceptance criteria

- [ ] At least two embedding/chunking versions registered.
- [ ] Production deployment references a registry version, not hardcoded string.
- [ ] Promotion requires documented approval step (manual OK for portfolio).

## Dependencies

- [5.2](5.2-mlflow-server.md)
