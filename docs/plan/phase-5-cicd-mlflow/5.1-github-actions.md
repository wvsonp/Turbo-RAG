# 5.1 GitHub Actions pipeline

## Goal

On push/PR: lint → test → `terraform validate` → docker build → push → `helm upgrade` (dev); prod gated on main + approval.

## Scope

- `.github/workflows/` 
- **GitHub OIDC → GCP Workload Identity Federation** (replace bootstrap JSON keys)
- Terraform plan comment on PR optional

## Prerequisites

- Phase 1 Artifact Registry + Helm

## Acceptance criteria

- [ ] PR workflow passes on clean main.
- [ ] CI uses WIF—no long-lived GCP JSON key in GitHub secrets.
- [ ] Failed test blocks deploy.
- [ ] `helm lint` and `terraform fmt -check` in pipeline.

## Production notes

- Prod deploy manual approval or environment protection rules.
- Separate WIF provider + SA per environment.

## Dependencies

- Phase 1 [1.4](../phase-1-foundation/1.4-artifact-registry.md), [1.8](../phase-1-foundation/1.8-helm-charts.md)
